# Kingdom Clash — เอกสารออกแบบเกม

เวอร์ชัน 1.0 • 8 ตุลาคม 2026

เกม Single Player แนว MOBA + Tower Defense + RTS + Resource Management พัฒนาด้วย HTML5, Phaser และ TypeScript สำหรับมือถือแนวนอน และนำไปครอบเป็น Android APK ผ่าน WebView ในภายหลัง

แพ็กเกจนี้เป็นเอกสารออกแบบ ไม่ใช่ซอร์สเกมหรือ APK ค่าตัวเลขเป็นค่าตั้งต้นสำหรับทดสอบสมดุล ยังไม่ได้ผ่านการทดลองเล่นจริง

## ลำดับการอ่าน

1. `01_GAME_DESIGN.md` — แนวคิด กติกา และขอบเขต
2. `02_HEROES_COMBAT.md` — ฮีโร่ เลเวล สกิล และการต่อสู้
3. `03_ECONOMY_ARTIFACTS.md` — ทรัพยากรและสูตรรวมไอเทม
4. `04_BUILDING_PATHFINDING_AI.md` — สิ่งก่อสร้าง เส้นทาง และ AI
5. `05_CAMPAIGN_FREEPLAY.md` — ด่านและ Free Play
6. `06_MOBILE_UI.md` — การควบคุมบนมือถือ
7. `07_PHASER_ARCHITECTURE.md` — สถาปัตยกรรมระบบ
8. `08_ANDROID_WEBVIEW.md` — การเตรียมแพ็กเกจ Android
9. `09_ROADMAP_ACCEPTANCE.md` — ลำดับพัฒนาและเกณฑ์ตรวจรับ
10. `10_IMPLEMENTATION_PROMPT.md` — พรอมต์ส่งต่อให้ AI ช่วยพัฒนา

## การตัดสินใจตั้งต้น

- Hybrid MOBA + RTS; มุมกล้อง Top-down เป็นข้อเสนอเริ่มต้น ยังไม่ได้รับการเลือกมุมกล้องโดยตรงจากผู้ใช้
- ควบคุมฮีโร่หลักหนึ่งตัวจากตัวเลือก 3–5 ตัว; ในทีมใหญ่ใช้ Bot ช่วย
- Grid สี่เหลี่ยม; สร้างได้ในเขตควบคุมของฝ่ายตัวเอง
- Campaign เป้าหมาย 30 ด่าน; ต้นแบบเริ่มด่าน 1–6 และ Free Play 1v1
- เล่นออฟไลน์; ไม่มี Multiplayer ในขอบเขตปัจจุบัน
- ไม่ต้องใช้บริการออนไลน์หรือ CDN เพื่อเล่นเกมที่แพ็กเกจแล้ว
