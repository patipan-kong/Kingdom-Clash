# ฮีโร่และระบบต่อสู้

## ฮีโร่เป้าหมาย

| ฮีโร่ | บทบาท | Q / W / E / R | Passive |
|---|---|---|---|
| Guardian | Tank | โล่กระแทก / ยั่วยุ / พุ่งชน / เขตพิทักษ์ | เกราะเพิ่มใกล้ฐาน |
| Ranger | Marksman | ลูกศรทะลุ / ยิงรัว / กลิ้ง / ฝนลูกศร | เพิ่มความเร็วโจมตีป้อมใกล้ตัว |
| Pyromancer | Mage | ลูกไฟ / พื้นไฟ / คลื่นผลัก / อุกกาบาต | เผาไหม้จากสกิล |
| Engineer | Builder | ซ่อม / เร่งป้อม / โดรน / Fortress Mode | ลดต้นทุนก่อสร้าง 10% |
| Shadow | Assassin | แทงพุ่ง / ควัน / ก้าวเงา / ลอบสังหาร | โบนัสโจมตีเป้าหมายโดดเดี่ยว |

ต้นแบบเริ่ม Guardian, Ranger, Engineer ให้สกิลทุกตัวมีผลจริงก่อนเพิ่มตัวใหม่

## เลเวลและแต้ม

LV1 เริ่มพร้อมหนึ่งแต้ม; LV2–20 ได้ครั้งละหนึ่งแต้ม รวม 20 แต้ม สกิล Q/W/E สูงสุดสกิลละ 5 ระดับ รวม 15; R สูงสุด 3 ระดับ; ค่าสถานะพิเศษ 2 ระดับ รวมพอดี 20

ข้อเสนอเพดานสกิลปกติ: rank n ต้องมีเลเวลอย่างน้อย 2n−1; Ultimate ต้อง LV6/11/16 การอัปสกิลต้องตรวจทั้งแต้มและเงื่อนไขก่อนหักแต้ม

XP เพื่อขึ้นเลเวลถัดไป: `80 + 25 × (level − 1)` ได้จากศัตรูและเป้าหมายในแผนที่ ฮีโร่ LV20 หยุดสะสม XP เพื่อนำไปขึ้นเลเวล

ไม่มี last-hit บังคับ: ฮีโร่มีส่วนร่วมโจมตีหรืออยู่ในระยะช่วยเหลือได้รับ XP เมื่อศัตรูตาย; Gold เข้าคลังฝ่ายหนึ่งครั้ง แบ่ง XP ระหว่างฮีโร่ที่มีสิทธิ์เพื่อไม่สร้าง XP เพิ่มตามจำนวนทีม

## ความเสียหายและสถานะ

แยกกายภาพ เวท และความเสียหายโดยตรง สำหรับเกราะไม่ติดลบ ใช้ `damage × 100 / (100 + armor)` ต้นแบบ clamp เกราะขั้นต่ำ 0 เพื่อหลีกเลี่ยงสูตรเกราะติดลบที่ยังไม่ได้ออกแบบ

สถานะเริ่มต้น: Stun, Slow, Burn, Shield ระบุ duration, source, stackingRule ในข้อมูล ไม่ให้ Burn ชนิดเดียวกัน stack ไม่จำกัด; รีเฟรชเวลาและเลือกค่าที่แรงกว่า

การโจมตีธรรมดามีระยะ ความเร็วโจมตี เวลาเตรียม และเป้าหมาย โจมตีเป้าหมายใกล้สุดที่โจมตีได้; แตะเลือกเป้าหมายเพื่อ override ไม่ยิงทะลุกำแพงทึบเมื่อไม่มี line of sight

## การตายและเกิดใหม่

Respawn วินาที: `min(25, 5 + 0.8 × (level − 1))` ตายแล้วหยุดโจมตี/เดิน ยกเลิกการเล็ง และล้างสถานะชั่วคราว คง Artifact, Gold, XP, skill ranks เกิดที่ช่องว่างใกล้ฐานด้วย HP เต็มและป้องกัน 2 วินาที ป้องกันสิ้นสุดเมื่อโจมตี

ขณะตายยังสั่งกองทัพและจัดการฐานได้; การซื้อไอเทมระหว่างตายอนุญาต ระยะร้านค้าใช้เฉพาะฮีโร่ที่ยังมีชีวิต

## คูลดาวน์

สกิลใช้ simulation time เดียวกับเศรษฐกิจและการเกิดใหม่; slow motion ลดทุกระบบพร้อมกัน การ pause ไม่ให้คูลดาวน์เดิน ค่าคูลดาวน์และความแรงอยู่ในข้อมูลฮีโร่ ไม่ hardcode ในปุ่ม UI
