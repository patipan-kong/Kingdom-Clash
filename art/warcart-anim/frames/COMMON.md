## Rules for every image
1. One generation per image. Use the built-in image tool, editing the input named for that image, with a genuinely transparent background (`transparent_background: true`). Keep the tool's alpha. Never use a white, coloured or chroma-key backdrop; never run background removal, chroma key, matting, alpha repair or any script on the pixels. Save each output exactly as returned, under the file name given.
2. Keep the canvas size and keep every part that does not change at EXACTLY its input position, size, colour and shading: the roof, frame, ironwork, pennant and cloth, and the wheels' positions, sizes and hubs. Never rescale, recentre or crop.
3. Same painted style, outline, light and camera as the input. The cart faces LEFT.
4. Nothing extra: no ground patch, ground shadow, dust, smoke, fire, glow, motion lines, sparks, text, border, figures or backdrop.
